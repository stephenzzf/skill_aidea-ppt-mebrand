# ME2026 Template Assets

These assets are extracted from the user-provided ME2026 / WhatsApp industry PPTX.

- `cover-bg.jpg`: cover background with the PPTX crop and horizontal flip applied.
- `index-bg.jpg`: index-page right-side background with the PPTX crop and horizontal flip applied.
- `meetsocial-group-logo.png`: cover MeetSocial Group logo.
- `meet-experience-cover-logo.png`: cover MEET EXPERIENCE logo.
- `meet-experience-footer-logo.png`: footer MEET EXPERIENCE logo rendered from the PPTX SVG.
- `meetsocial-footer-logo.png`: footer MeetSocial Group logo cropped from the PPTX image.
- `thank-you-bg.jpg`: default Thank You page left-side background, cropped from the source PPTX final slide.
- `thank-you-meetsocial-logo.png`: default Thank You page MeetSocial Group logo.
- `thank-you-official-qr.jpg`: default Thank You page MEET EXPERIENCE official account QR image.
- `deloitte-white-icons/`: selected white-background consulting icon geometry extracted from the user-provided Deloitte `.potx`, converted from OOXML custom shapes to transparent SVG/PNG, and recolored with ME2026 colors.

The source PPTX right-side contact-solution QR is intentionally omitted from this public template. The default Thank You page uses editable placeholder text `黏贴个人联系方式` in that position.

No AI-generated image assets are used in this folder. Confirm authorization before redistributing these brand assets outside the approved GitHub / Openclaw distribution path.

The default Thank You page assets come from the source PPTX final slide (`slide37`). The source package's `slide27` is a section divider, not the Contact Us / Thank You page.

The Deloitte-derived icon subset uses only white-background appendix slides (`slide296-slide315`) and explicitly ignores the black timeline page (`slide205`) and other dark/Deloitte-branded pages. These icons should be redistributed only when the source-template asset rights allow it.
