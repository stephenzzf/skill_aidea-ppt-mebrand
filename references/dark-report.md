# 深色汇报 · ME2026

用于季度经营复盘、服务组合、经营决策及同一产品的会前查阅与现场讲解。向用户说明预期画面：紫色品牌封面和章节页，正文、附件使用白底。说明使用者、阅读方式与内容权限后，沿用技能的方案确认流程。新内容决定章节数量、导航词和附件范围。产品附件沿用原稿独立版式，标题与左下品牌区沿用源位置，A/B 分页列在章节标签中。

## 画面标尺

来自校齐版 H2 Review 的原生对象，画布 13⅓ × 7½ 英寸。以下坐标以左上为原点，单位英寸，字号用 pt。固定章节标签、主标题、章节导航和品牌页脚沿用对应源版式的外框、内边距及对齐方式。新标题在原框内排版，正文从标题区下方开始；不要把原稿中的客户材料、业务事实、联系方式或部门名称带入新稿。

| 角色 | 基准位置与处理 |
| --- | --- |
| 封面 / 致谢 | 复用品牌图形，分离可编辑的标题、日期、联系信息。保留图像长宽比、留白、标识组合。 |
| 章节页 | 深紫品牌背景，左侧章号框 (1.55, 3.00, 3.25, 1.75)，字号 110。标题从 (4.92, 3.30) 起，44；副题在 y=4.12，22；解释在 y=4.78，15–20。按实际标题长度换行。 |
| 正文标题区 | 左边距 0.55，右边距约 0.55。章节标签 (0.55, 0.36)，12；判断句 (0.55, 0.70)，宽 12.23，典型字号 24。导航从 x=8.05 起，基线 y=0.38，每格约 0.76×0.28，10；当前节白字紫底，其余浅灰紫字。章节多时按层级缩短导航。 |

## 颜色、字体与组件

- 标题 **#2E1F6B**、正文 **#4D4A66**、弱化信息 **#8F8BA8**、章节高亮 **#5C0BE0**；蓝 **#2F7BEF**、青 **#0A9BEB** 用于指标或流程。深底正文用白色，次级文字可用 #E4DAFF。细小导航与弱标注使用加深的 #706B86；源稿浅灰紫用于足够醒目的元素。重要口径优先采用正文色。
- 原生渐变从 **#6110E2** 到 **#2F7BEF**，色标为 0% / 100%。指标块参考 45°，产品定义横条参考 0°。经济地使用渐变；连续大量数据使用白底和细分隔。
- 中文主要用等线，拉丁字母与数字主要用 Poppins；校齐页还有思源黑体 CN。按文字脚本指定字体。核对目标环境实际字体解析，缺字时选字宽接近的可用字体，并重看长标题、数字混排和密集表头。详细版可参考源稿的小字号附件；现场优先放大判断、指标和步骤，用备注承接讲解。
- 指标页先看到结论数字，再读原生趋势图或阶段；生态页按业务角色分组标识且保持比例；能力页保留层级与连接关系；三板块策略使用同宽卡片和状态标签，独立项目另起横区。挑战页平行陈列，盈利路径按同一维度比较。业务文字、图表、表格和流程保持可编辑。
- 选图、证据要求与编辑权限使用技能共用规则。真实标识只用有权使用的原件；测试用中性标识并标记示例。事实、流程和指标的数据结构独立于视觉参数，相同内容可以复用到标准样式。

- 两个正文母版的一级标题和正文占位符采用 90% 行距，正文段前 10 pt；其中一个母版的一般文本框使用 100% 行距、零段前段后。具体对象可覆盖继承值。长段落在同角色内调整文本框和分组，按实测换行核验。

## 新稿输入

通过 `npm run generate -- --style dark-report --input brief.json --use report --out output.pptx` 生成；`--use talk` 生成投屏用稿。以 [可编辑输入示例](../scripts/dark_report_sample.json) 作为字段和角色示例，按已确认的方案替换导航、页面顺序、业务文案、数字及统计口径。省略输入时使用虚构演示数据。经营口径、审批清单及多列比较使用全宽原生表格页（`role: table`）。首行为表头；`columnWidths` 按列提供正权重；`lead` 和 `note` 承载判断、样本及限定语。表格确实超过可用高度时，在逐页方案中按业务行拆开并重复表头。

## 验收参照

调用共用 QA 时传入 `--style dark-report`，按实际结构标注封面、章节与致谢的页码、角色。在同画布尺寸下叠加参考页与输出页的顶部、左下角。核对原生文字框及实际渲染基线、标识的可见图形范围；透明边距和母版继承须计入坐标判断。单看文字框起点无法发现内边距偏差。分别抽看章节、指标、生态、能力、策略、附件 A/B 与收束。检查导航高亮与实际章节一致，重点数字与单位相邻，产品双页可以逐栏连续阅读，投屏时能辨认判断与指示对象。按通用 QA 合同渲染全部页面，检查字体、溢出、对象与可编辑数据；PowerPoint 修改数值与表格、另存重开的结果单独记录。
